# Excalidraw

Create and inspect diagrams through Excalidraw’s official hosted MCP service.

## Setup

No account, API key or OAuth application is required. Install this bundle in OpenClaw and enable its MCP capability.

## Source and rights

[Official service documentation](https://github.com/excalidraw/excalidraw-mcp). The remote service is maintained by Excalidraw; this small connection bundle is authored and maintained by OpenClaw. The Cursor bundle format describes compatibility, not Cursor authorship. No upstream source, skills, hooks or logos are included. The bundled MIT license covers this adapter, not the remote service or its data.

## Permissions

Diagram tools can create or update content. Use disposable diagrams for testing. MCP App rendering depends on host support and is separate from basic MCP tool support.

# GoDaddy Domains

Find domain suggestions and check public domain availability through GoDaddy’s official MCP service.

## Setup

No account, API key or OAuth application is required. Install this bundle in OpenClaw and enable its MCP capability.

## Source and rights

[Official service documentation](https://developer.godaddy.com/en/docs/api-users/mcp). The remote service is maintained by GoDaddy; this small connection bundle is authored and maintained by OpenClaw. The Cursor bundle format describes compatibility, not Cursor authorship. No upstream source, skills, hooks or logos are included. The bundled MIT license covers this adapter, not the remote service or its data.

## Permissions

This endpoint exposes domain suggestions and availability only. It cannot buy domains, change DNS, or transfer ownership.

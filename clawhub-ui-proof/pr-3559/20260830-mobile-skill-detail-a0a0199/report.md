# Mobile skill detail proof

The public `session-migrate` route was captured from a real ClawHub Vite instance in system Chrome. Baseline and candidate use the same public read backend and fixture route.

- Mobile widths: 320, 375, and 430 px.
- Desktop regression width: 1280 px.
- Candidate behavior: closed install surface, 44 px bookmark and secondary-tab targets, single-row horizontally scrollable secondary tabs, and no document-level horizontal overflow.
- Protected boundaries: skill icon preserved; hero taxonomy typography and wrapping unchanged.

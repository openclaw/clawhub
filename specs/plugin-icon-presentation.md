# Plugin icon presentation

Plugin artwork fills its existing rounded tile edge to edge, without UI-added padding or stretching. Keep the outer tile and surrounding layout dimensions unchanged. The tile clips the artwork to its shape; the image preserves its aspect ratio. Do not inset artwork by publisher, official status, or asset digest.

Only supported bundled artwork represents a plugin. Keep the existing raster-to-hosted retry; if no plugin art loads, use the standard plug glyph except on curated home Featured Plugins rows and plugin detail. Those surfaces may fall back to the catalog-resolved official owner’s existing HTTPS profile logo. Mark it visibly as publisher branding, not plugin artwork. Search and other lists keep the generic plug. A missing, disallowed, or broken publisher logo also falls back to the plug. Never inherit skill art, fetch replacement artwork, or write the publisher logo into package metadata.
